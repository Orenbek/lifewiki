# 人生 Wiki

这里沉淀我的想法、观点、经历和知识，默认写给未来的自己。允许认识暂未成熟，也逐步把相关材料整理成能连续阅读的主题。

- [知识与表达](knowledge/README.md)：从建设人生知识库的起点开始，记录我如何沉淀想法，以及为什么希望把它们分享出去。
- [人生选择](life/README.md)：记录我对幸福与自由的理解，以及主动追求财富、重视战略如何服务于想要的生活。

- [Wiki 宪法](_meta/constitution.md)规定长期目标、知识边界和维护原则。
- [内容编辑协议](../skills/personal-wiki-editor/SKILL.md)规定讨论、对齐、成文与主题综合。
- [Wiki 维护协议](../skills/wiki-documentation/SKILL.md)规定检索、归位、元数据、索引和链接。
